Isaac CRT is a small, unofficial, free graphics mod for The Binding of Isaac: Repentance+.

[b]Subscribing alone does NOT install the graphics mod.[/b]
This Workshop companion only adds an Isaac CRT entry to the Mods menu. It makes no gameplay changes and requires no REPENTOGON. The graphics run in a separate, manually installed native DLL.

[h2]Five treatments, two keys[/h2]
CRT Core offers a clean CRT look; CRT Studio adds a richer phosphor treatment. LCD Light and LCD Strong offer two LCD cell treatments, and VHS adds analog tape texture.

[b]F7:[/b] CRT Core > CRT Studio > LCD Light > LCD Strong > VHS > Off.
[b]F6:[/b] Flat/Curved for CRT Core, CRT Studio and VHS; Ghosting On/Off for LCD Light and LCD Strong. No action in Off.
A brief notification shows each change. Selections are saved; LCD ghosting defaults to Off.

[h2]Install the graphics mod separately[/h2]
Get the standalone DLL from [url=https://github.com/vici1129/isaac-crt/releases]GitHub Releases[/url] when a build is available.
Close Isaac, extract the package, and copy its opengl32.dll beside the actual rendering executable, isaac-ng.exe. If opengl32.dll already exists, stop: do not overwrite another mod's DLL. Launch normally through Steam.
Linux/Proton and REPENTOGON layouts need the [url=https://github.com/vici1129/isaac-crt/blob/main/INSTALL.txt]installation guide[/url]; preserve existing launchers and DLL overrides.

[h2]Disable or remove[/h2]
Use F7 to select Off for untreated gameplay. To uninstall, close the game and remove only Isaac CRT's opengl32.dll.
Disabling or unsubscribing from this companion does NOT disable or remove the native DLL. The companion is optional; the graphics mod works without it.
