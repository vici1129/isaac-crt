# Changelog

## 0.1.0 — Unreleased

The first release is in preparation. No GitHub Release has been published yet.

- Five treatments: CRT Core, CRT Studio, LCD Light, LCD Strong and VHS, plus Off.
- F7 cycles treatments; F6 toggles CRT/VHS curvature or LCD ghosting.
- Optional LCD ghosting, off by default and shared between both LCD treatments.
- Saved treatment, curvature and ghosting selections, with brief notifications.
- Windows and Linux/Steam Deck installation, including REPENTOGON launch options.
- Corrected VHS colors and improved effect alignment at different resolutions.
- Fixed treatment failures during Proton startup and improved graphics cleanup
  when resizing or closing the game.
- Optional Workshop companion with a link to manual installation instructions.
