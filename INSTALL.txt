Isaac CRT — Installation

Close Isaac. In Steam: Isaac > Properties > Installed Files > Browse.
Copy opengl32.dll from this package beside isaac-ng.exe.
With REPENTOGON, place it beside Repentogon/isaac-ng.exe in the game folder.
On Windows, launch through Steam. On Linux, set the launch option below first.

LINUX / STEAM DECK
In Steam: Isaac > Properties > General > Launch Options. Paste one option:
Standard Proton:
WINEDLLOVERRIDES="opengl32=n,b" %command%
With REPENTOGON:
echo "%command%" | sed 's|isaac-ng.exe|REPENTOGONLauncher/REPENTOGONLauncher.exe|' | WINEDLLOVERRIDES="opengl32=n,b" sh

CONTROLS
F7: CRT Core > CRT Studio > LCD Light > LCD Strong > VHS > Off.
F6: Flat/Curved for CRT Core, CRT Studio and VHS;
    Ghosting On/Off for LCD Light and LCD Strong.

UNINSTALL
Close Isaac and remove the opengl32.dll you copied into the game folder.
On Linux, remove WINEDLLOVERRIDES="opengl32=n,b" from Launch Options.
